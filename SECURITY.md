# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is paramount for patient scheduling applications. If you discover a vulnerability or security issue:

1. Please **do NOT** open a public issue.
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the repository maintainer directly.
3. Include detailed steps to reproduce the vulnerability and potential impact.

We will review, patch, and deploy a resolution promptly.
