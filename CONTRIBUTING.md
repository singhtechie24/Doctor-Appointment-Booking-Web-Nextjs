# Contributing to Glowing Smiles

Thank you for your interest in contributing to the **Glowing Smiles** Doctor Appointment Booking platform!

## Development Workflow

1. **Fork or Clone the Repository:**
   ```bash
   git clone https://github.com/singhtechie24/Doctor-Appointment-Booking-Web-Nextjs.git
   cd Doctor-Appointment-Booking-Web-Nextjs
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Branching:**
   Create a descriptive branch for your feature or bugfix:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Environment Setup:**
   Ensure `.env.local` is configured with test environment variables as outlined in `README.md`.

5. **Testing & Linting:**
   ```bash
   npm run lint
   npm run build
   ```

6. **Submit a Pull Request:**
   Push your branch and open a PR with a concise description of your changes.
